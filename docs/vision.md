WH3 Mod Manager

A modern, lightweight, cross-platform mod manager
focused on usability, maintainability and openness.

Goals

- Lightweight
- Fast
- Native-feeling UX
- Cross platform
- Easy to contribute
- Open source first
- Modern web technologies
- Long-term maintainability

Non-goals

- Replace Steam
- Become a game launcher
- Bundle hundreds of features
- Require a database
